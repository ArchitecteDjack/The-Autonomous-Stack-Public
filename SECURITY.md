# Security

Please report security issues privately rather than opening a public issue when the report could expose credentials, payment details, private infrastructure, or a practical exploit.

This public repository must never contain API keys, tokens, wallet private keys, seed phrases, private IPs, production `.env` files, internal logs, customer information, or paid-pack source.

The free sample is intended for evaluation. Review scripts before running them with elevated privileges, especially `install.sh` and the optional systemd setup.
