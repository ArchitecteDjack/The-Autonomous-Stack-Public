# FAQ

## Is the free sample a real runnable agent?
Yes. It includes a file-backed task queue, deterministic transforms, an agent loop, tests, an installer, and an optional BYO-LLM adapter.

## Does it require a cloud LLM?
No. The deterministic core runs without an LLM. Optional reasoning can use an already-installed supported CLI.

## Is The Autonomous Stack fully open source?
No. This repository publishes the free sample and public documentation. Paid packs and the production backend remain outside the public repository.

## Is there native Ollama, llama.cpp, MCP, or DeepSeek Harness support?
Not in this public V0.1 unless explicitly documented and tested. Do not treat generic Markdown/CLI compatibility as a native integration.

## What is x402 used for?
Paid packs can expose an HTTP 402 payment challenge so software agents can discover, pay for, and retrieve a pack through the production service.
