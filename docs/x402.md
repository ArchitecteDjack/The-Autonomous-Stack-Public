# x402

The production service exposes paid-pack endpoints using an x402 v2 HTTP 402 payment challenge.

Current audited characteristics:

- network: Base mainnet;
- asset: USDC;
- paid pack route pattern: `GET /api/v1/pack/{id}`;
- unauthenticated request: HTTP 402 with payment metadata;
- retry mechanism: `PAYMENT-SIGNATURE`;
- successful delivery format: ZIP is the documented target response.

High-level flow:

```text
GET /api/v1/pack/{id}
        ↓
HTTP 402 + PAYMENT-REQUIRED
        ↓
client authorizes payment
        ↓
retry with PAYMENT-SIGNATURE
        ↓
ZIP
```

The public audit verified the unauthenticated 402 challenge. It did not execute a real paid settlement, so this repository deliberately does not claim an independently verified end-to-end purchase.

For current machine-readable information, use the production discovery surfaces listed in `docs/discovery.md`.
