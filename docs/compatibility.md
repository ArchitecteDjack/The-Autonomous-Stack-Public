# Compatibility

| Target | Status | Notes |
|---|---|---|
| Claude Code | Generic-compatible | Supported through the BYO-LLM CLI adapter when the `claude` CLI is installed and logged in. |
| Kimi Code | Generic-compatible | Supported through the BYO-LLM CLI adapter when `kimi-code` is installed and logged in. |
| Codex CLI | Generic-compatible | Supported through the BYO-LLM CLI adapter when `codex` is installed and logged in. |
| Ollama | Not verified | No native integration is claimed in this public V0.1. |
| llama.cpp | Not verified | No native integration is claimed in this public V0.1. |
| MCP | Not verified | No native MCP integration is claimed in this public V0.1. |
| DeepSeek Harness | Not verified | No native DSH integration is claimed in this public V0.1. |

The sample itself does not require an LLM. Its deterministic core is the fallback and can be exercised offline.
