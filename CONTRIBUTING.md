# Contributing

Contributions are welcome for the public repository scope: documentation, examples, tests, portability fixes, and improvements to the Free Sample Agent.

Please do not submit paid-pack source, production backend code, credentials, private infrastructure details, customer data, or secrets.

For code changes, keep the free sample runnable without a mandatory cloud API and preserve deterministic fallback behaviour. Add or update tests when behaviour changes.

Keep `DIGEST.json` synchronized with public-facing Markdown and material behaviour changes. Keep the digest at or below 8,000 tokens.
